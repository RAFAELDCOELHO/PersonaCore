<objective>
Run the blind calibration: apply M1 to one calibration fact exactly as it will be applied to the
target, and score it with the same adversary at the same budget.

Purpose: this is Phase 14's step 2 for erasure — the run that produces the floor's input while the
target is still untouched and unscored. Blindness here is structural, not a promise: the derivation
rule was committed at 19-03 before this adapter existed, the fact set is disjoint from the target and
disposable, the discount exists so the number cannot be chosen to be cleared, and git order is the
proof (§Q2's four structural properties).

The floor is NOT locked in this plan. Measuring the rate and locking the constant are separate
commits on purpose — that is the `0425fdc` → `921a6bc` pair, and separating them is what lets a
reader re-derive the constant from committed inputs rather than take it on the same commit's word.

Output: the erased calibration adapter, its scored arm record, and its collateral curve.
</objective>
