<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| draws → questions | Treating 1008 clustered draws as i.i.d. Bernoulli trials yields intervals far too narrow; the unit crossing is where that happens |
| per-family budgets → cross-family comparison | A0 has 9 draws and the attacks have 64, so any "at least once" comparison is unequal-budget unless it is explicitly held to the common prefix |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-08-01 | Repudiation | A draw-unit rate published as a question-unit rate | mitigate | `unit == "question"` is a required field on every proportion; `aggregate_by_fact`'s draw rate is explicitly converted, with the trap named in a comment |
| T-18-08-02 | Repudiation | ASR@1 reported as "one attempt" while measuring a deterministic decoder | mitigate | Rung 1 carries a required greedy label; `ASR_RUNG_GREEDY_NOTE` is a pinned literal |
| T-18-08-03 | Repudiation | A zero published only at the flattering question denominator | mitigate | Both the question-level and fact-level (n=8) denominators are emitted in the same record — both or neither |
| T-18-08-04 | Tampering | A new "suffix-aware" scoring predicate silently replaces the committed one | mitigate | `contains_value` imported unmodified; `grep` acceptance forbids a local `def contains_value`/`def normalize` |
| T-18-08-05 | Repudiation | A four-family unique count that quietly compares 9 draws against 64 | mitigate | The 9-prefix count is the headline; the 64 count is labelled and excludes A0, enforced by `_prove` |
| T-18-08-SC | Tampering | package installs | accept | Zero installs; `pyproject.toml` sha256-pinned |
</threat_model>
