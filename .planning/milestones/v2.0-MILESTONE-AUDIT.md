### Correction: the original W2 conflated two unrelated issues

The first draft of this audit recorded a single "W2 — DEBT-02's `evaluate.py` half unwired, carried from v1.0, repeat offender." Investigation showed that merged two things that are not the same, and got the headline one backwards.

It is a manually-run CLI, and it is the canonical producer of the v1.0 headline **2.1066** cited in `README.md:42`, `docs/REPORT.md:255/279/377`, `results/results.md:9` and `demo.ipynb`, plus `results/samples.md`. Retention PPL is a different function in a different file: `retention_perplexity()` at `src/personacore/evaluation/perplexity.py:148`.

- **W2a — not debt.** The masked/unmasked split is deliberate and frozen (commit `ca14a89`, 2026-07-31). `retention_perplexity`'s own docstring: *"This wrapper is THE ONLY sanctioned PPL for curve points; the unmasked `perplexity` remains the v1.0 headline semantics (2.1066) and must not be used for retention curves."* Masking `evaluate.py`'s PPL would change a number published in five documents and break a frozen decision. What is actually stale is DEBT-02's *wording*, which still names `evaluate.py` and predates the split.
- **W2b — the real carried item, and it was never about PPL.** v1.0's WARNING-1 was about **warm sampling**: `evaluate.py:136-143` passes no `forbid_ids`, so a re-run can crash on any of the 7645 dead ids. So the honest verdict is neither "delete a dead file" nor "critical two-milestone recurrence." It is one documentation amendment plus one optional one-line hardening of a script that is run by hand and whose outputs are already committed.
