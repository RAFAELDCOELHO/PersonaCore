<objective>
Build the cost record's shape and its refusals **before any number goes into one**, so the structural
properties CAL-05 asks for are facts about the artifact rather than notes beside it.

Purpose: CAL-05's requirement is that 4.77 h/point is a **floor for noised points, not a mean**. A
comment saying so is defeated by the first consumer who reads it as a mean. Three mechanisms make it
structural instead, and this plan lands all three: distinct field names with no bare mean to read; a
`_prove`-style refusal in the sizing function when the ceiling is absent; and sizing against the
ceiling because the K ratchet only permits increases. CAL-01's half is the same discipline applied to
the training leg — a record whose provenance keys are required rather than defaulted, and a timing
protocol with warm-up discards and a recorded denominator.

Output: `scripts/phase23_cost.py` and `tests/test_phase23_cost.py`. No measurement is taken here —
23-08, 23-10 and 23-11 fill this schema.
</objective>

physically cannot read a mean off a record that contains no mean, and a single `h_per_point` field
anywhere in a Phase-23 artifact is the warning sign `23-RESEARCH.md` Pitfall 5 names. `draws_per_min`
is forbidden **as a bare key** because it is the quantity whose stop-rate dependence the floor/ceiling
split exists to expose — per-condition rates must be named
`draws_per_min_floor` / `draws_per_min_ceiling`.

**(c) `validate_record(record, *, kind)`.** Refuses with `SystemExit` when any required key is
absent, naming the missing key and stating that a record missing provenance is refused rather than
defaulted. Also refuses when any `FORBIDDEN_MEAN_KEYS` member is present at any nesting depth (walk
the structure — a nested `h_per_point` is the same defect), and when any numeric field is non-finite.

or condition mix-up, and it would size Z in the direction the ratchet cannot rescue.

**(d) `size_sweep(*, generation_record, sweep_points, k)`.** Returns a mapping with the projected
hours computed **from `h_per_point_ceiling`**, plus a `floor_hours` field computed from
`h_per_point_floor` recorded **beside** it for disclosure. `_prove` that the record validates first,
so a floor-only record raises before any arithmetic happens. Docstring: state the ratchet reason —
`mitigation_gate.py:248-255` only lets K increase, so a sweep sized against the floor and found too
expensive has no rescue in the cheap direction; sizing against the ceiling is the only direction the
ratchet permits.

**(e) The timing helper.** `timed_region()` — a context manager, or `time_iterations(fn, *,
warmup, iterations)`. Import torch **inside** it. Call `torch.mps.synchronize()` immediately before
`t0` and immediately before `t1` when the active device is `mps`. Default `warmup >= 4` and
`iterations >= 20`; refuse smaller values with a message stating that a rate with no denominator is
exactly the kind of figure this project has had to retract, and that 3–4 discarded warm-up iterations
were measured as the point where the per-micro-step figure stabilizes on MPS. Return the mean **and**
the iteration count, never the mean alone.

Record in the docstring, as a measured fact with its source: the generation loop is already
implicitly synchronized every token at `src/personacore/generation/core.py:79` (`tok = int(next_id)`
is a device→host sync), so Phase 18's committed rates are honest — but training has **no** per-step
host sync at all, which is why the explicit synchronize is not optional there.

**(f) A `__main__` self-check** that runs `validate_record` on a complete synthetic record (passes),
on one missing a key (refuses), on one carrying a bare `h_per_point` (refuses), and on one whose
ceiling is below its floor (refuses); print each outcome and exit non-zero on any surprise.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a measured rate → a sweep budget | The rate was measured on the un-adapted base where 45–56 of 64 draws stop-terminated. A noised adapter that stops emitting EOS runs the full `max_new_tokens=48` on every draw. |
| record producer → record consumer | 23-13 sizes Z from this record and the K ratchet forbids the cheap correction. A mis-read field is unrecoverable in the direction that matters. |
| queued GPU work → wall clock | Training has no per-step host sync on MPS, so an unsynchronized bracket measures queue submission, not completed work. |
