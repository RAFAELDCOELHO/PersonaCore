<objective>
Execute the DP arm's first run at σ=0, on MPS, at the production shape — and let the blindly
committed verdict decide whether the milestone proceeds.

Purpose: DPSGD-06 exists because every correctness bug in this class *improves* utility. A DP-SGD
implementation that clips the averaged gradient, gets the sensitivity wrong, reuses its RNG or noises
after averaging produces better numbers than a correct one, so a good-looking frontier is exactly
what a broken implementation looks like. At σ=0 the mechanism runs with the noise term zeroed, so the
arm should reproduce the unmitigated control to within seed variation. It is the cheapest diagnostic
this milestone has, and it only means anything if it runs **before** any noised point exists and
against a floor that was pinned **before** its number was visible. Both of those are now facts about
git.

This run doubles as CAL-01's DP-path training measurement at n=8: the seam is active, the shape is
production, and the wall clock is bracketed with the synchronize discipline.

Output: `results/phase23_sigma_zero.json`, committed after the control floor and before any noised
record.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a correctness bug → a better-looking frontier | Every failure in this class improves utility, so the frontier cannot detect it. σ=0 is the only cheap instrument that can. |
| pinned floor → run-time comparison | A floor recomputed at run time is a floor that could move; the pin exists so it cannot. |
| σ=0 → the first noised point | D-04 commits to zero noised points on a breach. That commitment is only real if the ordering is checkable. |
| clip bound C → the diagnostic's meaning | A binding C at σ=0 makes the arm differ from the control by clipping, not by the DP arithmetic. |
