**`test_fake_averaged_gradient` (V-18, FAKE 1 — clip the averaged gradient).**
Mutation: drop the per-micro-step drain. In-process form: subclass `DPSGD` overriding
`absorb_record` to skip the `p.grad = None` drain, run two micro-backwards, and assert D-05 axis 4
(D-16 invariant 1) raises `RuntimeError`. Then run the real `DPSGD` over the same inputs and assert
it completes. Also assert the **consequence**, not just the refusal: with the drain dropped, the
accumulated norm after two records exceeds `C` — i.e. true per-record sensitivity became `N*C` — so
the reader can see what the guard is protecting against, not only that it fired.

**`test_fake_wrong_sensitivity` (V-19, FAKE 2 — a second clip constant).**
Two halves, both required:
  - **AST half**: build a mutated `dpsgd.py` source STRING introducing `self._c2` used as the clip
    bound, and pass it to `_assert_single_clip_constant` — the same function the live test runs.
    Assert `AssertionError`.
  - **Runtime half**: subclass `DPSGD` clipping to `2 * self.C` while the sensitivity check still
    reads `self.C`, and assert `RuntimeError`.
  - **State the runtime check's limitation honestly in the docstring**: `C*(1+tol)` is **one-sided**
    — it catches a second constant LARGER than `C` (the dangerous direction: clip to 2C while telling
    the accountant C) and does not catch a smaller one. The AST guard catches both directions, which
    is why both halves exist and neither is redundant. Do not present the runtime check as complete.

**`test_fake_noise_after_averaging` (V-20, FAKE 3 — build `divide -> noise`).**
Mutation: subclass `DPSGD` overriding `finalize` to divide the accumulator by `accum` BEFORE adding
noise. Detection, and **read this carefully because the naive detector does not work**:
  - **At sigma = 0 the mutation is INVISIBLE**: `(S + 0)/N` and `S/N + 0` are the same bytes. D-06's
    σ=0 identity therefore does NOT catch FAKE 3, and the plan must say so rather than assert a
    detection that does not happen.
  - **The working runtime detector is a fixed-generator differential at sigma > 0 AND accum > 1**:
    run the real and the mutated `finalize` from the same generator state and assert the released
    private terms differ (`not torch.equal`). At `accum == 1` they coincide, so the probe must
    parametrize `accum` and assert the `accum == 1` case is a KNOWN BLIND SPOT, documented, not a
    passing detection.
  - **The working structural detector is statement order.** Add
    `_assert_noise_precedes_divide(source_text, *, method="finalize")` to
    `tests/test_phase22_dpsgd_ast.py`-style helpers (define it in THIS file and also call it from
    the live AST module, or define it there and import it — one definition either way), asserting
    that in `finalize`'s body the statement index of the `torch.normal` call is strictly less than
    the statement index of the `BinOp(Div)` whose right operand is `accum`. Feed it the real
    `dpsgd.py` bytes (GREEN) and a mutated string with the order swapped (RED). This is the detector
    that catches FAKE 3 at sigma = 0 and accum = 1, where the runtime differential cannot.

**`test_fake_rng_reuse` (V-21, FAKE 4 — an in-step `manual_seed`).**
Two halves:
  - **AST half**: a mutated source string with `self._g.manual_seed(1234)` inside `finalize`, passed
    to `_assert_no_forbidden_between_noise_and_step` and to the no-reseed-outside-`__init__` walk.
    Assert both raise.
  - **Runtime half**: subclass `DPSGD` re-seeding `self._g` at the top of `finalize`; run two steps
    and assert D-16 invariant 4 raises because the pre-draw state of step 2 equals the pre-draw state
    of step 1. Also assert the **consequence**: without the guard, the two steps' noise draws are
    `torch.equal`, i.e. the same noise was released twice.

Every probe carries a meta-guard that the UNMUTATED case passes, so a probe that reddens because the
harness is broken rather than because the fake was applied cannot be mistaken for a detection.
