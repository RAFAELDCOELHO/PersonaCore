<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| binding fixture → attack corpus | The fixture binds the question set and its `seed_index` assignment; the surface string a consumer builds at runtime is deliberately not bound, and that asymmetry must be recorded, not assumed |
| corpus artifact → both arms | One recorded prompt object dispatched twice is the only structural defence against the two arms silently diverging |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-05-01 | Information Disclosure | A locked value reaches a question-derived prompt portion in any family | mitigate | Widened `assert_no_value_in_prompt` on realized ids for all four families; watched RED |
| T-18-05-02 | Tampering | The corpus is regenerated between the two arms, silently unpairing them | mitigate | Corpus is a committed artifact with a recorded sha256; the run reads `prompt_ids`, never rebuilds |
| T-18-05-03 | Spoofing | An external service silently supplies attack text, violating ATK-01 | mitigate | AST scan forbids network imports and URL literals under `scripts/phase18_*.py` |
| T-18-05-04 | Denial of Service | `KeyError` on the 32 reserved held-out probes a third of the way through the gated tier | mitigate | `"reserved"` is an explicit `source_family` value, cross-checked against the fixture flag at 32/32 |
| T-18-05-05 | Repudiation | A corpus that cannot be re-derived cannot support any claim about what was asked | mitigate | Determinism test in-process and cross-process by sha256; byte-equality against the committed artifact added in 18-14 |
| T-18-05-SC | Tampering | package installs | accept | Zero installs; `pyproject.toml` sha256-pinned |
</threat_model>
