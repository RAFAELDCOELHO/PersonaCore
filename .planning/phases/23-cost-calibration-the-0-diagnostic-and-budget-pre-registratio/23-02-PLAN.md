<objective>
Close the transitive half of SC3's import guard, and watch both halves fail before trusting either.

Purpose: SC3 requires `scripts/mitigation_budget.py` to sit in a module the gate is **structurally
unable to import**. The static AST scan for that already exists and bites — it was watched RED during
research — but it scans only `scripts/mitigation_*.py`, and `scripts/erasure_gate.py` (which the gate
DOES import) sits outside that glob. So the route *gate → erasure_gate → budget* is invisible to it.
The accountant's own guard pairs a static half with an **out-of-process** probe and the project calls
that the standard; the gate/budget guard has only the static half. D-09 closes it at ~12 lines,
reusing the proven local shape.

This plan writes **no budget module** — 23-09 does. It writes the guard, and the watched-RED evidence
that tells 23-09 exactly what the module may and may not contain.

Output: `tests/test_phase23_budget.py` carrying the transitive probe plus a recorded RED observation
for the two static assertions.
</objective>
