<objective>
Score the never-taught adapters trained in 23-08, at the K pinned in 23-13, and commit a record whose
provenance the frozen Phase-25 gate will accept.

Purpose: `scripts/mitigation_gate.py` at `:341-441` is FROZEN and holds three `_prove` calls at the
one choke point where an extraction floor's provenance is checked. It requires the floor to name
`arm == "never-taught"` and to report **≥ 2 distinct seeds**, with its own message stating that *"a
single-seed floor is NOT a noise floor, it is ONE DRAW."* That refusal fires in Phase 25 and the gate
cannot be relaxed. D-08 resolved this in the cheapest phase that can resolve it by scheduling the
never-taught arm at the same N seeds as D-03's control; this plan produces the scored record that
satisfies it.

The frontier's lower-left floor and the relearning reference are the two consumers named in the
training record. Both read this one scored artifact — that is what "scheduled once and consumed
twice" means, and no second training call exists anywhere in the phase.

Output: `results/phase23_never_taught.json`, committed.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phase 23's floor record → Phase 25's frozen gate | Three `_prove` calls at one choke point, two phases later, in a file with no correction path. A record that fails there fails after the sweep has been run. |
| draws → questions | `extraction_ceiling`'s locked unit. A draw-denominated count deflates the rate AND narrows the bound in the same direction, so the error never surfaces in the output. |

| a scored artifact → a published bound | Phase 23 measures the floor; Phase 25 computes X from it. |
