<objective>
Commit the σ=0 diagnostic's decision rule, its reduction and its artifact naming **before any Phase-23
number exists**, and make the pre-registration ordering a property of git rather than a promise.

Purpose: three of this phase's four items are pre-registrations — they are committed before the first
run or they are a post-hoc peek. D-03's floor must be reduced by a function committed blind; D-04's
halt must be a rule with a watched failing branch; DPSGD-06's "first executed run" must be checkable
against git's object graph rather than asserted in prose. This plan is the moment all three are
closed, and it deliberately runs **before** any plan that executes anything.

It also fixes the one defect class this repository keeps repeating: plans naming artifact paths the
code then refuses. `scripts/phase23_prereg.py` becomes the single place every Phase-23 result path is
derived from, in the shape `teach_persona.fact_bin_path` already uses for the same reason.

Output: `scripts/phase23_prereg.py` (blind rule + path constants) and `tests/test_phase23_prereg.py`
(three ancestry guards + the D-04 both-branch test with its watched RED).
</objective>
