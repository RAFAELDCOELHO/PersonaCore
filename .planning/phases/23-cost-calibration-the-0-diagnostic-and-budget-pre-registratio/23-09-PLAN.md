<objective>
Pin the measured noise floor where D-03 says it goes, in the shape the codebase already proved
honest, and land it **before** the σ=0 run so the ordering is a fact rather than an intention.

Purpose: the floor is now a measurement (23-08). Making it a pre-registration requires three
properties, all of which `scripts/phase19_floor.py` already demonstrates: an ancestry-visible
ordering against the artifact it came from, re-derivation from the committed artifact through the
pinned function on every suite run, and literal assignments and nothing else. The third property also
satisfies, for free, the hard import ceiling this module inherits by being named `mitigation_*.py` —
a ceiling measured to have **zero headroom**.

The Z values themselves are NOT written here — CAL-01 and CAL-05 have not been measured yet. 23-13
adds them to this same module after 23-11. That is exactly why this module must not be frozen.

Output: `scripts/mitigation_budget.py` with the floor and its `_PROVENANCE` sibling, plus the two
structural tests `phase19_floor.py` carries.
</objective>
