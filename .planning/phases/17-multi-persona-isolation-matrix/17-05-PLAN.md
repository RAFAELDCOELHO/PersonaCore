<objective>
Build `scripts/phase17_persona_gate.py`: the GPU pre-flight that measures whether the **un-adapted
base** can already produce any of the 24 minted values, writes `results/phase17_personas_report.md`
with a `PENDING` verdict and every base completion quoted verbatim, and refuses to clobber that
report once a verdict is recorded.

Purpose: ISO-01's blocking human GO/ADAPT verdict (ROADMAP SC2) needs an artifact to judge. This plan
builds the instrument and its guard; plan 17-07 runs it and takes the verdict. RESEARCH F-13 records
what this measurement buys: if `probe_guessability` proves the base produces zero containments of
each minted value, an off-diagonal hit later cannot be the base's own prior — it must come from
adapter *i*. The ISO-03 column is then the higher-powered confirmation, not the only control.

That inference holds **only if the probe ran on the base**. Probing anything that carries a trained
adapter measures a taught model, which is LESS likely than the base to emit the minted values, so the
gate would come back flatteringly clean and a human would sign GO on the wrong model — the exact
failure class this phase exists to catch, arriving through the phase's own gate.

Output: the committed pre-flight driver and the verdict-blocking test. No report yet — 17-07 owns
the run.
</objective>
