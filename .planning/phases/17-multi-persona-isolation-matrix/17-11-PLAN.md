<objective>
Add the `--replicate` mode to `scripts/phase17_isolation.py`: read the four recorded sweeps, select
the worst-colliding pair with the committed `worst_pair`, score the seed-scoped replicate sweeps,
write `results/phase17_replication.json`, and append the ISO-05 addendum to
`results/phase17_isolation_report.md` without touching a byte above it.

Purpose: ISO-05 needs a committed rendering path. Plan 17-08's own governing rule is that "the whole
writer is committed BEFORE it produces a number" — a report whose text is written after the numbers
is a report written to fit them. `results/phase17_replication.json` and the addendum are public
committed artifacts, so they need the same discipline as `results/phase17_isolation_report.md`, and
an executor improvising a script in plan 17-10 to produce them after the numbers exist would break
exactly the rule the rest of the phase is built on.

This is a separate plan rather than a fourth task in 17-08 for one mechanical reason: 17-08 is
already at its task budget and any sibling plan touching `scripts/phase17_isolation.py` in Wave 4
would collide with it on file ownership. Wave 5 is the earliest wave where this file is free, and it
is still strictly before plan 17-10 runs the mode.

Output: the committed `--replicate` mode and its tests. It produces no number here — plan 17-10 runs
it.
