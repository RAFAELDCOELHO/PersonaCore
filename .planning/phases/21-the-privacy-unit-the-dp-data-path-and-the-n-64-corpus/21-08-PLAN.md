<objective>
Close the D-11 side channel: make replay VOLUME a function of public quantities only, and give
`train()` the additive seam D-10 needs so the teaching bin holds facts only.

Purpose: `_prepend_replay` sizes replay as `want = int(round(replay_ratio * teaching_tokens))`
(`scripts/teach_persona.py:338`), and `teaching_tokens` is the sum of the FACTS' OWN token lengths —
measured 7,581 across 8 facts, varying with the fact VALUES from 867 to 1,041, a 174-token spread.
So today the volume of "public" data in the lot is a function of private content, and without this
correction the un-clipped public-gradient argument does not hold: the public term stops being
independent of the private records. This is the phase's own named defect class — a quantity DECLARED
public whose VALUE is a function of private data — and it is closed the way that class must be
closed, by refusing the property rather than the name.

Output: the public constant and its single computing site in `scripts/teach_persona.py`, the
additive seam in `src/personacore/training/loop.py`, and `tests/test_phase21_replay_volume.py`.
