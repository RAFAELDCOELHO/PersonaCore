    close over `second_person` per family id at import time, so threading a runtime `forms` through
    them would mean rebuilding the tables per call. Bypassing them for the non-`None` branch keeps
    the `None` branch byte-identical AND covers both registers, because `_render_family`'s
    `second_person` argument is the same one the closures pass.
