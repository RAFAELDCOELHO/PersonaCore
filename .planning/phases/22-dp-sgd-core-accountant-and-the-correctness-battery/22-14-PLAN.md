<objective>
Close the second SC3 defect: `delta_quadrature` — the INDEPENDENT ORACLE the whole DPSGD-03 argument
rests on — returns `+inf` and values above 1.0 for a quantity that is a probability, without
refusing.

Purpose: an oracle that can return a non-finite delta is not one that can be compared to anything.
Measured in this tree: `delta_quadrature(0.000440884929509763, 75.3129260813192)` returns `inf`;
sweeping μ ∈ [74.0, 78.0] at eps=1e-4 gives **404 `inf` cells and 472 cells above 1.0**, with the
first `inf` at μ=74.951 and condition 1 not firing until μ=75.355. Condition 1 bounds a SINGLE
`math.exp` argument while the Simpson loop sums 20001 terms with weights up to 4, so it fires ~0.19
too late in z — and its own message already names this case, *"the separated integral overflows
(z < 0)"*.

Output: a headroom budget for the SUM rather than for one term, and an upper-bound refusal whose
boundary is measured rather than transcribed.
</objective>
