Add the three step methods to `DPSGD`. Together they own everything between accumulation and
`optimizer.step()`; nothing else may write `.grad` in that window (D-03's surviving rule).

`begin_step(self)`:
  - Zero `self._accum` — a list of `torch.zeros_like(p)` buffers, one per trainable LoRA parameter,
    allocated once in `__init__` and zeroed here (never reallocated, so the single-write assertion's
    `data_ptr()` identity is stable).
  - Reset `self._writes = 0` and `self._records = 0`. **Do NOT reset `self._clip_bind_count`** — it
    is a run-lifetime counter, so the D-06 identity test can assert the bound never bound across the
    WHOLE run rather than only on the last step.

`absorb_record(self)` — called after each micro-batch's `backward()`:
  - **D-16 invariant 1 (drain).** Before reading, refuse if any trainable parameter's `.grad` is
    `None` (nothing to absorb — the caller skipped a backward). After absorbing, drain by setting
    `p.grad = None` for every trainable parameter. The NEXT call refuses unless every `.grad` was
    freshly created by a single backward — implement by recording, at drain time, that the state is
    "drained", and refusing at entry if the previous call did not drain. Message must state the
    consequence D-01 names: `backward()` accumulates, so without the per-micro-step zero, record
    *i*'s clip would see records 1..*i* summed and true per-record sensitivity would silently become
    `N*C`.
  - **The per-record GLOBAL clip.** Compute the L2 norm across ALL trainable LoRA gradients as one
    vector (`torch.linalg.vector_norm` over the concatenated squares, or `sqrt(sum(g.pow(2).sum()))`)
    — a **global** norm, not per-parameter. Docstring records D-01's rejected alternative (b): tensor
    hooks fire per-tensor mid-backward and a per-record global norm is not knowable until
    `backward()` completes, so hooks would force per-**parameter** clipping, a different and weaker
    sensitivity bound than DPSGD-01 states.
  - `coef = 1.0 if norm <= self.C else self.C / norm` — reads `self.C`, annotated
    `# reads self.C (D-17): the single clip constant. A second constant here is FAKE 2.`
    `coef` is **exactly 1.0** when the clip does not bind, and `x * 1.0` is bit-identical in
    IEEE-754 for finite `x`. **In the `else` arm — the only place the clip actually scales —
    increment `self._clip_bind_count`.** That counter is what turns "a finite bound that does not
    bind" from an assumption into an observation, and it is how D-06's identity input is represented
    now that `math.inf` is refused (Task 1 refusal 4). Comment says exactly that, and names
    `22-CONTEXT.md` § *Claude's Discretion*'s sanctioned latitude as the basis.
  - Add `g * coef` into `self._accum[i]` in place. `self._records += 1`.
  - **D-16 invariant 2 (sensitivity).** After clipping, refuse unless the clipped global norm is
    `<= self.C * (1 + self.sensitivity_tolerance)`. Reads `self.C` again — the same single source.
    Message names the fake: *noise scaled to the wrong sensitivity*.
  - Drain: set every trainable `p.grad = None`.

`finalize(self, accum)` — called AFTER `replay_fn` has run, so `.grad` holds the public term exactly:
  - **D-02's staging, in this order and no other:** `self._accum` already holds the SUM of clipped
    per-record gradients. Draw noise and add it **to the sum**; divide by `accum` **last**; then
    perform the single combining write.
  - **The noise draw (D-07).** One `torch.normal(mean=0.0, std=self.sigma * self.C,
    size=buf.shape, generator=self._g, device=..., dtype=...)` per accumulator buffer. Annotate the
    line `# reads self.C and self.sigma (D-17). std = sigma * C, sigma being the noise MULTIPLIER.`
    **No branch on `sigma == 0`** — `torch.normal` with `std=0.0` returns exact zeros AND advances
    the generator, which is precisely what makes "noise never got added" have nowhere to hide.
    **The expression is exactly `self.sigma * self.C` and nothing else** — plan 22-09's V-25
    assertion 3 requires a two-operand `Mult` over two `self` attributes with no `Constant` operand,
    and Task 1's finiteness refusal is what keeps this product from being `nan` at `sigma == 0`.
  - **D-16 invariant 4 (generator state).** Capture `self._g.get_state()` before and after the
    draws. Refuse if the two are `torch.equal` (the generator did not advance — the draw did not
    happen). Refuse if the PRE-draw state equals `self._prev_gen_state` from the previous step (the
    generator was re-seeded in between — FAKE 4). Store the post-draw state into
    `self._prev_gen_state`. Message names FAKE 4: *RNG reused across steps*.
  - `private = (accum_buf + noise) / accum` — the `/N` LAST. Comment records D-02's trap: with
    `/accum` inherited from `loop.py:175`, `.grad` after each backward would hold `g_i / N`, so
    clipping THAT to `C` sets true per-record sensitivity to `C*N` while the accountant is told `C`.
    That is DPSGD-04's wrong-sensitivity fake arriving for free, and it converges fine.
  - **The single combining write (D-01, D-05 axis 3).** For each trainable parameter, exactly ONE
    assignment to `p.grad`: `p.grad = private` when `p.grad is None` (no public term), else
    `p.grad.add_(private)`. Increment `self._writes` once per parameter. Refuse unless
    `self._writes == len(self._params)` — a **measured count**, not a described sequence. Also
    refuse if any accumulator buffer aliases any `.grad` (`buf.data_ptr() != p.grad.data_ptr()`).
