`_assert_single_clip_constant(source_text, *, class_name, allowed_attr)`
  - FAKE 2's structural half (D-17). **"Looks like a clip constant" is PINNED HERE as a decidable
    AST rule, not left to the executor** — this is a specification, and plan 22-04 Task 3 calls it
    with `allowed_attr="C"` and needs that call green on correct code:
      * **Scope** — the method containing the PER-RECORD CLIP, located as the method whose body
        contains an `ast.BinOp(op=ast.Div)` whose **LEFT operand is a `self.<attr>` read** — that is
        `self.C / norm`, unique to `absorb_record`. **The locator must be this narrow, and the
        narrowing is load-bearing:** a broader "an `ast.Compare` OR an `ast.BinOp(op=ast.Div)` over a
        `self.<attr>` read" ALSO matches `finalize`, whose D-16 invariants mandate
        `self._writes == len(self._params)` (an `ast.Compare` with a `self.<attr>` on the left) and a
        `self._prev_gen_state is not None` guard. Two matching methods make the rule undecidable, and
        a guard that unions across them yields `{"C", "_writes", "_prev_gen_state"}` — reddening plan
        22-04 Task 3's hard equality against `{"C"}` **on correct code**. If a future edit ever puts a
        `self.<attr> / …` division in a second method, do NOT widen the allow-set to recover — pass
        the method name explicitly instead, so the scope stays exact rather than the membership
        growing. **NOT the noise-bearing method:** `finalize`'s
        `std=self.sigma * self.C` has TWO legitimate `self` operands, so any predicate scoped there
        can never equal `{"C"}`. The `std=` product has its own dedicated guard — plan 22-09's V-25
        assertion 3 requires a two-operand `Mult` over `self.sigma` and `self.C` with no `Constant`
        operand — so scoping this one to the clip leaves no coverage gap.
      * **Membership** — a `self.<attr>` read is clip-bearing iff the `ast.Attribute` node is a
        DIRECT operand of an `ast.Compare` (its `left` or one of its `comparators`) or a DIRECT
        operand of an `ast.BinOp` whose `op` is `ast.Div`. *Direct* means the `Attribute` IS the
        operand, not nested inside another expression. Under this rule
        `coef = 1.0 if norm <= self.C else self.C / norm` contributes `{"C"}`;
        `norm <= self.C * (1 + self.sensitivity_tolerance)` contributes nothing new (the comparator
        is the `Mult`, not either attribute); and an `AugAssign` target such as
        `self._clip_bind_count += 1` contributes nothing at all.
      * **Assertion** — `assert clip_bearing == {allowed_attr}`, hard equality, never a subset. An
        empty set fails it too, so a collapsed scope reddens rather than passing over nothing.
  - Also assert no CLASS-BODY float/int `Assign` (a class attribute — NOT a `self.<attr> = ...`
    inside a method) other than the ones in an explicit `_ALLOWED_CLASS_CONSTANTS` frozenset defined
    in the test.
  - Meta-guard: `assert class_name in {n.name for n in ast.walk(tree) if isinstance(n, ast.ClassDef)}`.
