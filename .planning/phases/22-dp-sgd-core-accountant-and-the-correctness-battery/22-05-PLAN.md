**Signature is exactly `(sigma, steps, delta)` — three parameters, no `clip_norm=`.** RESEARCH F4:

Implementation:
  - **The explicit σ = 0 branch, FIRST, before any arithmetic.** `if sigma == 0.0: return
    math.inf`. Docstring carries the mathematics, not just the guard: σ → 0 means μ → ∞, so
    `Phi(mu/2 - eps/mu) -> 1` and `exp(eps) * Phi(-mu/2 - eps/mu) -> 0`, giving δ → 1 for EVERY
    finite ε; since no finite ε satisfies δ ≤ the target, the infimum over admissible ε is `+inf`.
    This agrees with the mechanism-level statement — σ = 0 releases a deterministic function of the
    data, which is (∞, δ)-DP for any δ < 1 and nothing better. **It is the mathematically correct
    return value, not a guard papering over an exception** — though `1.0/0.0` is separately
    confirmed to raise `ZeroDivisionError` in CPython 3.11 (it does not return `inf`), so the branch
    is also operationally required.
