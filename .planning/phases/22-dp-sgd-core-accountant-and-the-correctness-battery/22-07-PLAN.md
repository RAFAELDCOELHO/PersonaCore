<objective>
Land the MPS RNG slot with a backward-compatible load, and prove the two things DPSGD-05 actually
gates on: every pre-Phase-22-shaped checkpoint still resumes, and a kill→resume **through
`train(resume_from=…)`** reproduces a **bit-identical reported ε** rather than merely a matching
loss curve.

Purpose: the slot is five lines now and a full sweep re-run later. The subtlety is that
`checkpoint.py:142` restores `rng["cuda"]` with a **subscript**, not `.get()` — copying that form for
`mps` would make every checkpoint written before this phase raise `KeyError` on resume, which is
precisely the backward compatibility the requirement demands. And D-14's honest half: the DP path
uses the separately-named `dp_noise_rng` slot, so `rng["mps"]` is recorded as
**required-but-unexercised** rather than dressed up as load-bearing.

Output: the `mps` slot in `checkpoint.py`, and `tests/test_phase22_checkpoint.py` (V-15, V-16, V-17).
</objective>

  1. **Exact `==`, not a tolerance.** `epsilon_a == epsilon_b`, byte-for-byte on the float. Docstring
