<objective>
Compute the curve verdicts on CPU from the 44 committed records, apply the promotion rule that was
committed before any of them existed, and — if candidates exist — promote and replicate **all** of them
at K=48.

Purpose: the verdict is the cheapest stage in the phase and the one most exposed to hindsight. Two
things protect it. First, the per-point verdict cannot be computed at point time at all: the gate's
did-the-curve-cross check reads **whole-curve** inputs, so this stage necessarily runs after the sweep
and necessarily reads the committed artifacts rather than live state. Second, the promotion rule was
committed in plan 25-01 while `git ls-files 'results/phase25_point_*'` was empty — so "promote all
clearing candidates" cannot be narrowed now that the list is known.

The pre-registered null is live and expected: ε is 519.698 at σ=0.5, and condition (a) is **zero
tolerance** — one leaked question of 416 already exceeds the ceiling. An empty candidate list is a
result, costs exactly zero tail compute, and must be recorded as a branch that was reached rather than
as an absence of output.

Output: `results/phase25_promotion.json` and its guard.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a rule written before the data → a rule narrowed after it | only the commit graph separates them, and it is checkable |
| a truncated leg → a curve verdict | `mitigation_point_verdict` reads whole-curve inputs; a partial leg silently changes the did-the-curve-cross answer |
| a K=16 reading → a K=48 claim | numerically identical ε, different statistical power |

| T-25-97 | Information Disclosure | a verdict computed against a truncated curve | mitigate | each leg's whole-curve input lengths are asserted equal to that leg's committed point count |
| T-25-98 | Spoofing | a K=16 reading published as a K=48 promoted claim | mitigate | promoted readings assert `draws_per_question == FULL_FIDELITY_K` with its source; the three-field cache identity refuses the K=16 draws and the K=16 cache is asserted unchanged |
| T-25-99 | Repudiation | the pre-registered null presented as "no result produced" | mitigate | `empty_frontier_reached` is a boolean present either way; when true, the record still carries the arm existentials, the capacity branch and all 44 verdicts, and the tail cost is recorded as exactly 0 |
