<objective>
Measure the two resource quantities the sweep's shape depends on and that no committed record
supplies: the **per-record** gradient-norm distribution on the DP path, and adversarial **scoring**
throughput at both extremes.

Purpose: `C` is pinned nowhere, sits outside `MECHANISM_KEYS`, and yet `std = sigma * C` — so two
points at equal nominal σ and different `C` carry different noise scale. Picking `C` by convention
would be picking the noise scale by convention. The only committed norm evidence is **batch-level on
the non-DP path** (max 2.20–2.30, `bound_count: 0`); the per-record distribution the DP path actually
clips against has never been measured. Meanwhile the one noised point in the repo binds **12800 of
12800** at `C = 1.0` — 100% clipping, which at fixed σ buys nothing because ε does not improve.

And adversarial *training* cost is already bounded (161.124 s/point non-DP, 1383.3 s for `dp_n64`);
what is unmeasured is adversarial **scoring**, roughly 95% of the spend. D-14 requires **both**
extremes probed before the schedule is committed, never one extrapolated.

Both are resource measurements, and this project permits a resource budget to be measured before
pre-registration. No gate threshold is read, chosen or approached.

Output: `scripts/phase25_calibrate.py`, two committed calibration records, and their guard.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a calibration adapter → the sweep's point set | a calibration run under an unnamed prefix could be mistaken for a sweep point and enter the artifact |
| a measured resource number → a pre-registered threshold | resource budgets may be measured before pre-registration; outcome thresholds may not. The boundary must stay visible |
| batch-level norms on the non-DP path → the per-record norms the DP path clips | two different quantities; conflating them would pick the noise scale by accident |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-53 | Spoofing | a calibration adapter entering the sweep's point set or the frontier artifact | mitigate | a named `CALIBRATION_PREFIX` with the `phase23_sigma0` precedent, plus a test asserting no member of `ORDERED_POINT_KEYS` begins with it and no point-record path names it |
