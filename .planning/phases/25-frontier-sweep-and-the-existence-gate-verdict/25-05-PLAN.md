<objective>
Build the stall watcher for a 4.5–6.3 day unattended run, with its threshold derived from measurement
and its inability to act proved structurally.

Purpose: the driver runs as a LaunchAgent with `KeepAlive` **FALSE** precisely so that nothing
automatically re-enters a point without passing the deliberate resume logic — an automatic restart
would violate D-10. The watcher exists to make a kill *diagnosable*, not recoverable. That distinction
is one line of code away from collapsing, so it is enforced by an AST walk over the watcher's own
module: no `kill`, no `terminate`, no `Popen`, no `launchctl`, no `unlink`, no write to any path other
than the stall record.

N is not a convention. The measured worst case is not in the draw loop at all — `dp_n64` training runs
**23.06 min** with no per-shape line — which is exactly why the beat is a wall-clock timer in the
driver's outer loop rather than an event on the prompt counter.

Output: `scripts/phase25_watch.py` and `tests/test_phase25_watch.py`, both halves watched.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a detector → a remediator | one `subprocess.run` in the watcher turns detection into automatic restart, re-entering a point outside the deliberate resume logic and violating D-10 |
| a 6-day silence → a diagnosis | without a heartbeat the kill is a zero-traceback mystery; the last beat is what says *where* it died |
| an event-driven beat → a 23-minute training leg | a prompt-counter beat forces N ≥ ~35 min and detects nothing useful |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-21 | Elevation of Privilege | the watcher acquiring the ability to kill or relaunch the sweep | mitigate | `FORBIDDEN_ACTIONS` enforced by AST over the watcher module; the import set is asserted to exclude `subprocess`; a planted `launchctl` call is watched failing in `tmp_path` |
| T-25-22 | Repudiation | a killed point silently resumed as a fresh attempt because nothing recorded the stall | mitigate | the stall record carries the last beat's five fields verbatim and appends rather than overwrites, so a 6-day run leaves a history |
| T-25-23 | Denial of Service | a stall threshold so coarse it detects nothing, or so fine it fires on every n=64 training leg | mitigate | N = 5 min is asserted to sit above the measured 5.03-min ceiling draw gap and below the 23.06-min training leg, recomputed from `phase23_cost.json` in the test |
| T-25-24 | Tampering | the watcher writing to the heartbeat and corrupting the driver's own record | mitigate | AST assertion that every write's path operand resolves to `stall_record_path`; the heartbeat is opened read-only |
| T-25-25 | Spoofing | a detected stall read as a watcher crash by whatever supervises it | mitigate | a detected stall exits **0**, asserted through a real `subprocess` invocation of `main()` |
| T-25-SC | Tampering | npm/pip/cargo installs | accept | Zero installs; stdlib only; `pyproject.toml` byte-unchanged (RPT-03) |
