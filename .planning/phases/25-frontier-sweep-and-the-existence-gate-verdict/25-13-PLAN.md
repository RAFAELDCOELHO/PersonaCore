<objective>
Measure, at both capacities and before any sweep point exists, how far the σ=0 DP path differs from
the seam-off path — and commit that difference as a **prediction** rather than discovering it later as
an anomaly.

Purpose: CTRL-02's own body already records that the control is *not* bit-identical to the seam-off
path and that chasing that identity would be a mistake. n=8 was probed in Phase 23 (72/72 LoRA tensors
agreeing to 2.178e-07 relative); **n=64 has never been probed at all**, so this is a first measurement.
Committing it in advance is what turns "someone later notices a difference and 'fixes' it" into "the
difference was predicted, bounded and recorded", and it is what D-04's armed tripwire enforces.

D-06 draws the line that keeps D-01 reachable: only the `dp_fn=None` **comparator** is renamed. The
σ=0 control point keeps arm identity `dp_n8` / `dp_n64` — it *is* a DP sweep point under CTRL-02 — and
is separated by **prefix only**.

Output: `results/phase25_probe2_tensors.json` and its guard.
</objective>
