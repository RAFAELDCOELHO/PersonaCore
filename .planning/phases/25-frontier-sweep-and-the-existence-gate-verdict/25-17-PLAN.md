<objective>
Run the 36 interior points as pinned, and record what the run actually did — including every kill,
every resume and every stall record — so the 44-point set is complete and its history is legible.

Purpose: this is the phase's bulk spend, roughly 70–110 hours across four to six days. Almost
everything that makes it survivable was built before it started: the atomic block write, the
three-field cache identity, the shape-keyed resume, the wall-clock heartbeat, the detect-never-act
watcher, the LaunchAgent with `KeepAlive` false, and the driver's `{add, commit}` git surface. What
remains is discipline: **all 44 points run as pinned**, and the count is not re-opened at the moment of
spending. This project's own rule is that a resource number already published is not renegotiated when
paying it — a deviation requires an explicit scientific justification, never a cost-convenience
adjustment.

The expected outcome is the pre-registered null. That is not a reason to shorten the curve: `GATE-06`'s
did-the-curve-cross check reads whole-curve inputs, and a truncated leg reads INCONCLUSIVE rather than
NULL.

Output: 36 committed point records, an execution log, and a completeness proof over all 44 keys.
</objective>
