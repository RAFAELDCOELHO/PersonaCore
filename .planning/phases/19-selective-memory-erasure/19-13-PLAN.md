<objective>
Run the ERASE-02 reference arm: retrain the adapter without the target fact, and score it with the
same adversary at the same budget.

Purpose: `ROADMAP.md` SC6 obliges this phase to either run this arm or state in writing why it did
not. It costs **81 s** — verified three independent ways
(`results/phase17_training_run.log:19,39,58` at 82/80/80 s; `results/phase14_teaching_run.log:10→:16`
giving an 81 s window that also contains two full `masked_perplexity` sweeps over 270,203 targets).
Normally unaffordable, here it is a ninety-second call, so "we ran it" is the only defensible answer.

It is simultaneously a MECHANISM and a COMPARATOR, and the report must say so. As a comparator it is
the closest available operationalisation of "what would the model look like if it had never learned
this fact" — which is exactly the framing the pre-registration deliberately refuses to CLAIM
(`scripts/erasure_gate.py:33-36`, and `ERASURE_GOAL_FRAMING` at `:130-134`). Reporting it as a
reference point is fine; reporting the M1 result as *indistinguishable from* it is not, and would
violate the goal framing.

This plan shares no files with 19-12 and depends only on the locked floor, so it sits in the same
wave. On a single M3 the two runs serialise.

Output: the retrain adapter, its training log, and its scored arm record.
</objective>
