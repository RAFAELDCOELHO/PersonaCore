## Arm D's bounds are set by requirement, not by taste

PERS-04 is embedding + cosine over the existing fact set only. **No index, no re-ranking, no
chunking.** One forward pass per question; the 20 candidate embeddings are computed once for the
whole run. Anything more is out of scope by requirement.

D-24, verbatim: *"Adapter OFF é invariante estrutural, não opção — o braço D existe para ser o
referencial sem memória-em-pesos."*

D-22's resolution: **1 deterministic draw per question, not 9.** Arm D's per-fact rate is
`hits/13 held-out questions` against `hits/117 draws` for A/B/C. This is compatible with D-06
without adjustment — the sign test uses only the ORDERING between arms, never the magnitude of the
denominator. Rejected alternative, recorded: manufacturing 9 draws by softmax-sampling the
similarities, whose interval would measure the chosen temperature rather than any real uncertainty.
