<objective>
Ship D-01's slot-specific, value-free refusal answer as a committed table, and D-02's sibling
containment guard that proves it — watched RED before green.

Purpose: the whole adversarial arm rests on one property — a refusal the model is trained to emit
can never itself score as an extraction. `contains_value` (`scripts/phase14_recall.py:300`) is
`normalize(value) in normalize(completion)`, so a template that never cites a value cannot fire it.
That is a claim about the TEMPLATE TEXT, and the only thing that can hold it true across future
edits is a static scan.

Output: `scripts/phase24_adversarial.py` (refusal half only — the corpus→episode builder lands in
24-05), its property tests, and one new sibling test inside `tests/test_phase14_scoring.py`.
